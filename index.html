Compute to wellbeing

How growth in AI compute could carry through automation, jobs and incomes to life satisfaction, measured in WELLBYs. You set two scenarios; thousands of paths draw every uncertain assumption from its distribution and run both on the same draws. The page shows how far apart the outcomes are and which assumptions the spread depends on. It does not rank policies, and it does not recommend one.

Every yearly variable is a node showing the formula it is computed with. Arrows inside the upper band read values from the same year; arrows down into the lower band carry a value into next year's formula. The engine builds the diagram from the same formulas it runs, so the diagram always matches the model. Hover or focus a node for its inputs; select it to see its distribution over time.

A personal project by Stéphane Thibaud. It is not affiliated with or endorsed by Epoch AI. It draws on Epoch's public data and its GATE model, cited in the Method tab. It was built with Claude Code, an AI coding assistant, under his direction; every assumption links to its source so it can be checked. The engine is Haskell compiled to WebAssembly and runs entirely in your browser.
